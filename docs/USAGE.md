# 使用指南

## 1. 任务（Task）

- **新建任务**：填名称、目标描述（可粘贴 URL 列表）与目标（goal）；模式 `src`（漏洞挖掘）/
  `redteam`（攻防视角）/ `test`（功能验证，仅记录高危）。
- **范围（Scope）**：任务的授权边界。支持 `ip` / `cidr` / `domain` / `root_domain` / `subdomain`。
  执行侧的“范围闸”会在工具调用前检查目标；判断不了时会请求人工审批。
- **暂停/继续**：暂停后不再领取新意图，已领取的会尽快收尾。
- **预算**：token/时间/费用可按任务覆盖；超预算时 planner 会收口，而不是硬停。

## 2. 意图与图（Intent / Graph）

任务是“图”：`目标(goal) → 意图(intent) → 事实(fact) → 漏洞(finding)`。
意图是执行单元，由 planner 生成；worker 只执行、不新建意图。
界面上可以看到每个意图的状态、原因、耗时与产出。

## 3. LLM 配置

「系统 → LLM」支持多份配置（OpenAI 兼容 / Anthropic），可设优先级与并发槽：

- 保存后必须**设为默认**（`is_default`），否则 planner 没有可用模型；
- 多份配置会按优先级故障转移；限流/额度错误会进入冷却并自动重试；
- 单条配置可「测试」看延迟与返回。

## 4. 资产（Assets）

- 「功能 → 资产」可手工新增、从任务导入、导出；
- 类型：`domain` / `ip` / `url` / `cidr`；带技术栈、OS、备注；
- 资产会被任务引用（锚点），覆盖度按“资产 × 类别”统计。

## 5. 流量与证据

- 「系统 → 设置」开启 `traffic_capture` 后，经 `8799` 的请求会被录制；
- 「功能 → 流量」可按 host/状态/关键词检索，查看完整请求响应；
- 大包（>256KB）自动转存 blob，详情里显示 `@blob sha256:…` 指针，可下载原文；
- 漏洞详情可以绑定流量作为证据（报告里引用 + 快照）。

## 6. 出口代理池（支持账号密码）

「系统 → 出口」：

```
socks5://user:pass@1.2.3.4:1080
http://user:pass@5.6.7.8:8080
https://user:pass@9.8.7.6:443
```

- 不写协议时按“默认类型”补全；密码特殊字符会自动转义；
- 每行一个（可从文件导入），重复条目自动忽略；
- 每行可点「测试」验活并查看出口 IP；整池可「立即校验全部」；
- 开启后每个 worker 绑定一个出口，可按时间/请求数轮换；
- 池全挂时请求会失败（**不会回退直连**），避免暴露真实来源 IP。

## 7. 漏洞与报告

- worker 上报漏洞时会带**摘要 + 证据/PoC**（+ 流量绑定）；
- **详细报告**由「报告撰写」agent 读取证据后二次生成（可在漏洞行点「生成报告」/「重新生成」）；
- 报告为空时先看：`系统 → Agent → reporter` 是否启用、是否配置了 LLM；
- 验收：`accepted / rejected / duplicate / needs_evidence / needs_human`，被驳回的不会写正式报告；
- 去重：系统会生成“重复候选”（带评分与理由），人工或模型裁决后合并。

## 8. 线索板与记忆

- 线索板只存**客观观察**（谁在何时看到什么），支持纠偏（需填原因）；
- 记忆分层：会话上下文 → 索引（默认 25KB）→ Wiki（按需读取）→ 事实图；
- 长任务会在低峰期做“复盘（Dream）”，把过程沉淀成知识。

## 9. 导出与迁移

- 漏洞：`CSV / JSON / Markdown`（Markdown 含详细报告）；
- 资产 / 流量 / 代理池：CSV/JSON（代理池导出含明文口令，注意保管）；
- 整机配置：「系统 → 设置 → 导出配置」生成 JSON（含 LLM/代理/拦截规则等，含密钥）。

## 10. 权限与安全

- 单管理员账号；登录失败 5 次锁定 15 分钟；改密后旧会话立即失效；
- 所有工具调用受“范围闸/出口闸/拦截闸”约束；资产写回同样受拦截规则约束；
- 密钥：`bin/jwt.key`、`.env`、数据库口令只在服务器本地，切勿提交到任何仓库。
